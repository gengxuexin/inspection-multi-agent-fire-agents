# Agent Skill 文档

本目录是各 Agent 的**调用契约**。每份文档回答四个问题：

1. **通过什么关键词 / 形式调用** —— 上游怎么决定用它
2. **Agent 怎样识别调用** —— 它怎么确认这个请求该由自己处理
3. **输入格式** —— 需要什么参数
4. **输出格式契约** —— 返回什么、字段含义、异常怎么表示

---

## 为什么要有这份文档

系统里有三个 Agent（agent1/2/3）+ 一个网关（gateway）。它们之间靠 HTTP 契约相连，
但**契约只存在于代码里** —— 没有一处文档说明「什么情况下会路由到 agent2」、
「agent3 返回的 JSON 里 `risk_level` 是什么意思」。

这种「契约只在代码里」的状态有两个具体后果：

- **接入方要靠读源码才能对接**。新来的人不知道该调哪个端点、
  传什么字段、返回的 `status: "error"` 和 `status: "degraded"` 有什么区别。
- **改接口时没人知道会破坏什么**。改了返回结构，下游静默出错。

本目录把这层契约显式化，并**与代码保持同步** ——
`docs/skills/README.md` 里的校验脚本会核对文档与代码是否一致。

## 全局约定

### 认证

所有 `/api/*` 端点都需要 **内部 Token**：

```
X-Internal-Token: <AGENT_SHARED_TOKEN>
```

网关的 `/dispatch` 等端点用 **JWT**：

```
Authorization: Bearer <token>
```

JWT claims 携带权限上下文，检索层据此过滤：

```json
{
  "sub": "officer_001",
  "dept": "消防支队",
  "role": "officer",
  "clearance": 2
}
```

`clearance` 含义：`0=公开 1=内部 2=秘密 3=机密 4=绝密`。
**clearance 直接决定用户能看到哪些法规条文** —— 越界值会被收敛到合法区间。

### 统一响应信封

Agent 内部端点返回：

```json
{
  "status": "success | error | degraded",
  "...": "各 Agent 自定义字段"
}
```

| status | 含义 | 调用方应该 |
|--------|------|-----------|
| `success` | 正常完成 | 直接用结果 |
| `degraded` | 完成但走了降级路径（如 OCR 兜底、离线转写） | **可用，但要提示用户** |
| `error` | 失败 | 返回 503/500，不要当作「无结果」 |

★★★ `error` 与「查无结果」必须区分
------------------------------------
「检索不到相关法规」是**正常业务结果**（`success` + 空结果），
不是错误。把两者混淆会让调用方把正常的「查不到」当成系统故障去告警。

### 错误码约定

| 场景 | HTTP | status | 说明 |
|------|------|--------|------|
| 参数缺失 | 422 | — | FastAPI 自动校验 |
| Token 无效 | 401/403 | — | 鉴权中间件 |
| LLM 不可用（已降级） | 200 | `degraded` | 熔断器 OPEN 或重试耗尽 |
| LLM 不可用（无降级路径） | 200 | `error` | 上游全挂 |
| 上游 Agent 超时 | 200 | `degraded` | 网关熔断降级 |

## 路由速查

网关按**三级级联**决定路由（`common/router.py`）：

```
L1 规则（关键词）    ← 命中且 confidence ≥ 0.6 → 直接路由
L2 分类器（ML）      ← confidence ≥ 0.6 → 路由
L3 LLM 分类         ← 兜底
再不行 → human（转人工）
```

L1 关键词表：

| 意图 | 触发词 |
|------|--------|
| `vision` | 图片、照片、图像、视频、画面、看图、检查图、隐患、消防设施、灭火器、消火栓、通道、堵塞、消防水带、消防柜、安全出口 |
| `voice` | 语音、录音、音频、听一下、转写、识别这段 |
| `doc` | 生成文书、生成一份、生成个、写一份、写个、通知书、审批表、立案表、笔录、决定书、告知书 |
| `rag` | 兜底（其余全部） |

**强制路由**：请求体带 `force_kind` 可跳过识别（`rag`/`vision`/`voice`/`doc`）。

## 与代码的同步

本目录不是「写完就冻结」的文档。每次改动接口后跑：

```bash
python deploy/tools/verify_skill_docs.py
```

它会核对文档里写的端点、字段、关键词是否与代码一致，不一致就 FAIL。
